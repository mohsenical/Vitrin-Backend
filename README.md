## 📌 معرفی پروژه

**Vitrin Backend** هسته اصلی یک پلتفرم فروشگاهی مدرن و چندفروشندگی است که با هدف مدیریت جامع فرآیندهای یک فروشگاه اینترنتی توسعه داده شده است.

این پروژه با الهام از امکانات پلتفرم‌های بزرگ تجارت الکترونیک مانند دیجی‌کالا طراحی شده و بستری برای مدیریت کاربران، فروشندگان، محصولات، سفارش‌ها، پرداخت‌ها، موجودی انبار، نظرات، امتیازدهی، استوری‌ها و تعاملات کاربران فراهم می‌کند.

در توسعه این سیستم تلاش شده است تا با استفاده از تکنولوژی‌های مدرن، ساختاری امن، توسعه‌پذیر، مقیاس‌پذیر و قابل نگهداری ایجاد شود.

## 🧰 تکنولوژی‌ها و ابزارهای استفاده‌شده

### ⚙️ Core Technologies

- **Node.js** – محیط اجرای JavaScript در سمت سرور
- **Express.js** – فریم‌ورک توسعه API و مدیریت درخواست‌های HTTP
- **MongoDB** – پایگاه داده NoSQL برای ذخیره‌سازی اطلاعات
- **Redis** – سیستم ذخیره‌سازی داده در حافظه برای دسترسی سریع

### 📦 Libraries & Packages

| Package | کاربرد |
|---|---|
| **bcrypt** | هش کردن و محافظت از رمز عبور کاربران |
| **dotenv** | مدیریت متغیرهای محیطی |
| **jsonwebtoken (JWT)** | احراز هویت و مدیریت توکن‌ها |
| **multer** | مدیریت آپلود فایل‌ها |
| **nanoid** | تولید شناسه‌های منحصربه‌فرد |
| **swagger-ui-express** | مستندسازی و نمایش APIها |
| **yup** | اعتبارسنجی داده‌های ورودی |
| **zarinpal** | اتصال به درگاه پرداخت زرین‌پال |

## 🚀 نصب و راه‌اندازی پروژه

### 1. دریافت پروژه

```bash
git clone Vitrin-Backend
```

### 2. ورود به پوشه پروژه

```bash
cd Vitrin-Backend
```

### 3. نصب وابستگی‌ها

```bash
npm install
```

### 4. تنظیم متغیرهای محیطی

یک فایل با نام `.env` در ریشه پروژه ایجاد کنید:

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

REDIS_URL=your_redis_connection_url

JWT_SECRET=your_jwt_secret

ZARINPAL_MERCHANT_ID=your_merchant_id
```

> نام متغیرهای محیطی نمونه هستند و باید مطابق تنظیمات واقعی پروژه تغییر کنند.

### 5. اجرای پروژه در محیط توسعه

```bash
npm run dev
```

### 6. اجرای پروژه در محیط Production

```bash
npm start
```

> دستورات اجرا باید با اسکریپت‌های تعریف‌شده در package.json مطابقت داشته باشند.
